# FWKOG

Удобный клиент SPA-стука (Single Packet Authorization) под Windows — обёртка над
штатным клиентом [fwknop](https://github.com/mrash/fwknop).

Порт на сервере закрыт для всех. Приложение отправляет один зашифрованный
UDP-пакет, демон `fwknopd` его проверяет и открывает доступ Вашему адресу на
несколько минут. Ни своей криптографии, ни своего протокола у FWKOG нет: пакет
формирует и отправляет тот же `fwknop`, что и всегда — FWKOG только даёт ему
удобный интерфейс вместо командной строки.

## Что умеет

- Список настроенных стоек (конфигураций доступа) карточками.
- Кнопка «Стук» на каждой стойке — отправка SPA-пакета.
- Обратный отсчёт окна доступа на каждой стойке, по своему таймеру.
- Перенос стоек: импорт из существующего `~/.fwknoprc` и зашифрованный
  экспорт/импорт своим файлом.
- Светлая и тёмная темы.

Набор параметров — ровно тот же, что у `fwknop`. Под каждым полем подписано имя
переменной (`SPA_SERVER`, `ACCESS`, `KEY_BASE64`…), а редкие переменные правятся
текстом в блоке «Прочие переменные». Ничего сверх возможностей клиента FWKOG не
добавляет и ничего не урезает.

## Установка

Приложение портативное: распакуйте папку и запустите `FWKOG.exe`, установка не
нужна.

Отдельно нужен сам клиент `fwknop.exe`. FWKOG ищет его рядом с собой, в `PATH` и
в стандартных местах установки; путь можно указать вручную в настройках.

Данные с приложением не ездят: стойки хранятся на машине, в
`%LOCALAPPDATA%\FWKOG\configs.enc`, и шифруются мастер-паролем (scrypt +
AES-256-GCM). Мастер-пароль спрашивается при запуске; по желанию его можно
запомнить на сутки или неделю — тогда он хранится средствами Windows (DPAPI) и
только для текущей учётной записи. Перенести стойки на другую машину — через
экспорт в файл, а не копированием `configs.enc`.

## Окно доступа и таймер

Значение «Окно доступа, сек» отправляется серверу как `FW_TIMEOUT`. Демон
применяет его, но не выше своего потолка `MAX_FW_TIMEOUT` (по умолчанию 300 с).
Обратной связи от сервера у клиента нет, поэтому отсчёт идёт от запрошенного
значения: если сервер срезал окно, таймер покажет больше, чем есть на самом
деле. Без `FW_TIMEOUT` длительность задаёт сервер (`FW_ACCESS_TIMEOUT`, по
умолчанию 30 с) — тогда таймер не показывается.

## Запуск из исходников

Нужны Python 3.12+ и Node.js 20+.

```bash
cd frontend && npm install && npm run build && cd ..
pip install -r backend/requirements.txt
python main.py
```

Править вид без Python можно в браузере: `cd frontend && npm run dev` — там
подставляется заглушка бэкенда (стук не отправляется).

## Сборка портативного приложения

```bash
cd frontend && npm run build && cd ..
pip install pyinstaller
pyinstaller build/fwkog.spec
```

Готовое приложение появится в `dist/`. Релизные сборки делает CI по push'у
тега `v*`.
